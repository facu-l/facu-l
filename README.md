Sistema web de gestión para un centro deportivo, desarrollado en equipo como proyecto de Ingeniería de Software II (UNLP), con relevamiento de un cliente real.

- Módulo de pagos integrado con **Mercado Pago** (renovación automática de membresía)
- Sistema de **asistencia por QR** para el registro de socios
- Sistema de **puntos de canje** al cancelar clases
- Autenticación **JWT** y control de acceso por roles (cliente, recepcionista, dueño)
- Frontend en **React + TypeScript + Tailwind CSS**

🔗 Demo: https://sistema-cef.vercel.app/
🔗 Repo: https://github.com/canizafa/sistema-cef
